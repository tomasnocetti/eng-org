# Decisions

A dated log of org-level decisions in ADR style: context, options considered, what we chose, expected consequences, and which learnings informed it. Decisions are never edited after the fact; a reversal is a new decision that supersedes the old one.

Naming: `decisions/YYYY-MM-DD-<slug>.md`. Template: `templates/decision.md`.
